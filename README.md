<br>

**AIStack** is a published Android application that brings **100 AI tools into one place**. Users can discover and explore AI tools through categories and search, save their favorites, and quickly get back to the tools they've used recently.

### ✨ Features

| | |
| :--- | :--- |
| 🔍 **Search** AI tools | 🗂️ **Category-based** exploration |
| ❤️ **Favorite** AI tools | 🕒 **Recently used** tools |
| 🌙 **Dark / light** appearance | 📱 **Mobile-first** Flutter interface |
| 🔗 **Open tools** using URLs | 🏗️ **Feature-based** architecture |

### 🏗️ Architecture

AIStack uses a **feature-based Flutter architecture**. Features are separated into their own modules instead of living in one large screen, and the UI is built from reusable components.

```text
lib/
├── app/
├── core/
├── data/
├── models/
└── features/
```

### 🧠 Flutter Concepts Used

`Riverpod` · `Feature-based architecture` · `Reusable widgets` · `Theme management` · `Custom color scheme` · `Navigation` · `Local persistence` · `URL launching` · `Search / filtering` · `Favorites` · `Recently used tools`

### 🎨 Design

Purple-based primary color scheme, Lucide icons, and reusable design constants (`AppSpacing`, `AppRadius`, `AppColors`, `AppTextStyles`, `AppAssets`, `AppStrings`) for a consistent look across the app.
